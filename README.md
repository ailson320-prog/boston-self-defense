About the Project

Boston Self Defense is a frontend web development project designed to provide an accessible online presence for a self-defense training business.

The project demonstrates practical skills in website structure, styling, JavaScript programming, and frontend development.

Technologies Used

* HTML5 — Semantic page structure and content organization.
* CSS3 — Website styling, layouts, and visual presentation.
* JavaScript (ES6+) — Client-side programming and interactive functionality.

Project Goals

* Build a professional business website.

* Apply JavaScript to enhance the user experience.
* Develop practical frontend skills through a real-world project.

Getting Started

To run the project locally:

1. Clone the repository:

git clone https://github.com/ailson320-prog/boston-self-defense.git

2. Navigate into the project folder:

cd boston-self-defense

3. Open index.html in your browser, assuming it is the project’s entry file.

No framework installation or build process is required for a standard HTML, CSS, and JavaScript website.
